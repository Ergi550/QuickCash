# Quick Cash

## Overview
This project is designed to help users manage their finances efficiently.
The aim is to provide tools that allow for tracking expenses, creating budgets, and generating reports.

## Getting Started

### Prerequisites
- Node.js
- npm

### Installation
1. Clone the repo
   ```bash
   git clone https://github.com/Ergi550/QuickCash.git
   ```
2. Change your directory to the cloned folder
   ```bash
   cd QuickCash
   ```
3. Install the dependencies
   ```bash
   npm install
   ```

### Running the Application
To start the application, run:
```bash
npm start
```
